uprostřed epizody sama vstup nepovoluje. Žádné dodatečné ladění parametrů.

## Co změna skutečně způsobila

Vstupní signály klesly z388 na257, skutečné obchody zůstaly97. V obou
nákladových režimech má96 obchodů stejný vstup i výstup. Jediný jiný vstup
je pozdější o17 hodin, výstup zůstává stejný. Základní P/L tohoto obchodu
klesl z369,38 na333,44 USDT. Celkový rozdíl −53,59 USDT zahrnuje také
následné skládání kapitálu; není jen úsporou poplatků. Hypotéza, že tento
filtr omezí uskutečněné opakované obchody a zlepší výsledek, se nepotvrdila.

Kontrolní souhrn V18 se přesně shoduje s uloženým původním souhrnem všech
období, base i stress. Diagnostika ověřila součet P/L a nepřekrývání pozic
ve20 účetních knihách. Spuštění:

```
python -m elite.diagnostics_v51 --out elite/results/20261016_v51
```

## Reprodukce a omezení

skončil úspěšně; zkontrolované logy potvrzují shodné souhrny obou variant

Všechna použitá období jsou opakovaně prohlédnutá vývojová data. Rok2022
byl spotřebován dřívějším testem V38; rok2021 zůstává neotevřený. Bootstrap
není opraven na mnohonásobné hledání. Pětiminutová OHLC simulace nenahrazuje
skutečné provedení na burze. Žádné nasazení ani změny ostatních botů.

Další výzkum nesmí opakovat tento filtr pod jiným názvem. Snížení počtu
signálů bez změny uskutečněných obchodů není důkaz snížení obchodních nákladů.
