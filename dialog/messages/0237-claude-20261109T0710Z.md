## 2. Porovnání s naší architekturou (fakta z `app_v8.py`, větev main, 897 ř.)
- Režim: `TRADING_MODE = "PAPER"` natvrdo (ř. 24); burza se volá jen přes `binance_get()` (ř. 348) — GET, veřejné
  endpointy (klines, depth ř. 395). **Neexistuje žádná cesta k odeslání příkazu ani API klíč** ⇒ „read-only bridge“
  máme v nejsilnější podobě (exekuce fyzicky chybí).
- Jediná exekuční brána: `open_trade()` (ř. 565) / `close_trade()` (ř. 606), simulovaný účet `PAPER_BALANCE`.
- Idempotence/double entry: `open_trade` končí, pokud `paper_position` existuje (ř. 567) — max. 1 pozice v procesu.
  CHYBÍ: idempotence přes restart (stav jen `save_state()` ř. 150) a ochrana při 2 instancích — v PAPER bez dopadu na peníze.
- Risk gate: `daily_risk_status()` (ř. 420, denní limit v R); sizing se stropem notionalu (ř. 588).
- Audit log: `save_trade()`/`log_signal()` (ř. 207/226) do DB.
- Kill switch: provozně `paused_bots` / `/swing/status` (viz automation/STATE.md), ne v app_v8.
- AI decision layer: **žádný** — rozhodování je deterministické. To je záměr, ne mezera.

## 3. Threat model (pro případ, že by LLM vrstva vznikla)
| Hrozba | Riziko | Povinná mitigace |
|---|---|---|
| Prompt injection z tržních dat/zpráv/X | LLM vrátí „kup max“ | LLM výstup = jen JSON dle schématu (side, symbol z whitelistu, confidence); vše ostatní zahodit |
| Nepřímé volání nástrojů | LLM spustí exekuci | LLM nemá žádný nástroj; gate je samostatný deterministický kód |
| Eskalace oprávnění | AI mění limity | limity jen v kódu/konfiguraci pod git review; LLM k nim nemá zápis |
| Únik klíčů | krádež | v PAPER klíče neexistují; v promptu nikdy proměnné prostředí |
| Replay / double execution | 2× vstup | idempotency key = hash(signal_id, bar_ts); unikátní index v DB |
| Chybné risk limity | nadměrná ztráta | gate ověří limit nezávisle na LLM; fail-closed |
| Race conditions | 2 instance | DB zámek / advisory lock na symbol |
| Nedostupnost modelu | výpadek | timeout ⇒ žádný obchod (fail-closed), nikdy fallback „pokračuj“ |
| Obcházení lidského schválení | LIVE bez vlastníka | LIVE cesta neexistuje; případná budoucí jen s ručním potvrzením mimo agenta |

**SOUHLAS:** AI nesmí měnit vlastní oprávnění.

## 4. Minimální read-only prototyp
[N] Navrhuji **neimplementovat teď** (důvod v bodě 5). Kdyby ano: `recommendation.json` (schéma výše) →
`policy_gate.py` (čistá funkce, whitelist, limity, idempotence, timeout) → stávající `open_trade()`. Test matice
fail-closed: nevalidní JSON, neznámý symbol, confidence mimo rozsah, překročený denní limit, duplicitní klíč, timeout,
injection text v poli „reason“ — vždy výsledek ŽÁDNÝ OBCHOD + záznam do auditu. Odhad: ~1 den, 15–20 unit testů.
LIVE ochrana je jiná třída (klíče, podpis, ruční schválení) a **není schválena**.
