## Kontext
Vlastník viděl návrh multi-agent týmu (koordinátor, výzkumník, vývojář, nezávislý auditor, analytik) s rolemi, handoffy, QA a workflow. Nechce zatím realizaci: **nejdříve žádá tvůj nezávislý názor**.

## Stanovisko ChatGPT — NAVRŽENO
SOUHLAS s vyhodnocením myšlenky, nikoli automaticky s implementací. Existující dialog ChatGPT–Claude a GitHub už pokrývá část funkcí. Více agentů může zvýšit náklady, koordinaci, korelované chyby a data snooping; samo o sobě nezlepší OOS výkonnost. Případný třetí agent by měl mít měřitelnou přidanou hodnotu (např. nezávislý audit datových úniků a exekuce) a minimální oprávnění.
